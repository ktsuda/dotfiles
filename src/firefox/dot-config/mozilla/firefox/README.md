# Setup firefox

Requirement: Ubuntu 24.04.* LTS

## Install firefox

See [Install Firefox on Linux | Firefox Help](https://support.mozilla.org/en-US/kb/install-firefox-linux#w_install-firefox-deb-package-for-debian-based-distributions)

Remark: Never install the snap version!
